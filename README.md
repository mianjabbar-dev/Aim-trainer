#  Aim Trainer

A modern browser-based aim training game that helps improve mouse accuracy, reaction time, and clicking speed. Random targets appear on the screen, and players must hit them as quickly as possible before the timer expires.

## ✨ Features

* 🎯 Randomly generated targets
* ⏱️ Countdown timer
* ⚡ Real-time reaction time tracking
* 📊 Accuracy percentage calculation
* 🏆 Live score system
* 🔄 Restart game functionality
* 📱 Responsive design
* 🎨 Clean and modern user interface

##  Getting Started

1. Clone the repository:

```bash
git clone https://github.com/mianjabbar-dev/Aim-trainer.git
```

2. Open the project folder.

```bash
cd Aim-trainer
```

3. Launch `index.html` in your browser.

No installation or external dependencies are required.

## 🎮 How to Play

1. Click **Start Game**.
2. Random targets will appear on the screen.
3. Hit each target as quickly as possible.
4. The game records:

   * Score
   * Accuracy (%)
   * Average Reaction Time
5. Beat your previous high score before the timer runs out.
